واجهة Zaki API

أنشئ مفتاحًا خاصًا لاستخدام عقل زكي التعاوني داخل تطبيقاتك ومواقعك.

🔐 إنشاء مفتاح API جديد

يتطلب مفتاح الإدارة الذي تضبطه على الخادم باسم ZAKI_ADMIN_KEY. مفتاح API الناتج يظهر مرة واحدة فقط؛ احتفظ به في مكان آمن ولا تضعه داخل كود الواجهة الأمامية.

لم يتم إنشاء مفتاح بعد.

طريقة استخدام API

أرسل سجل المحادثة إلى المسار التالي باستخدام المفتاح في Authorization: Bearer.

POST /api/v1/chat
Authorization: Bearer YOUR_ZAKI_API_KEY
Content-Type: application/json

{ "messages": [{ "role": "user", "content": "Hello Zaki" }] }

المفتاح صالح لمدة سنة. الإصدار الحالي لا يوفر إلغاءً فرديًا للمفاتيح؛ غيّر ZAKI_API_SECRET لإبطال جميع المفاتيح الصادرة.
