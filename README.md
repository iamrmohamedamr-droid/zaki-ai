# Zaki AI v3 — Multi-Engine Assistant

واجهة عربية لمساعد متعدد المحركات، مع ذاكرة محلية داخل المتصفح، وتوجيه تلقائي بسيط للمهام، وتحليل الصور، وأدوات الجهاز.

## الجديد في v3
- **Zaki Core / Auto Pilot:** يختار Gemini افتراضيًا، ويوجه طلبات البرمجة إلى Groq عند توفره، ثم يجرب المحركات الاحتياطية بالترتيب عند فشل المحرك.
- **إصلاح Gemini:** تعليمات النظام منفصلة عن سجل المحادثة ولا تُرسل كرسالة مستخدم.
- **إدارة موحدة للمزودات:** Gemini وGroq وOpenRouter وMistral وNVIDIA NIM وCloudflare AI عبر إعدادات بيئية على الخادم.
- **Moondream Vision:** تحليل صورة مع تحقق من نوع البيانات وحجم الطلب وإظهار أخطاء الخدمة بشكل آمن.
- **ذاكرة محلية بلا Database:** IndexedDB أولًا، وLocalStorage كخطة بديلة. حفظ آخر 100 رسالة، مع مسح وتصدير المحادثة.
- **تحسينات الصوت والواجهة:** تشغيل/إيقاف أوضح، تصميم متجاوب، حالة اتصال الخادم والمحركات المضبوطة.
- **تقوية أساسية للـ API:** حدود أحجام الطلبات، تحديد عدد الرسائل وطولها، منع التخزين المؤقت، وعدم كشف تفاصيل الاستثناءات الداخلية.

## هل يحتاج قاعدة بيانات؟
لا. المحادثات تُحفظ على نفس المتصفح والجهاز باستخدام IndexedDB/LocalStorage. لن تتزامن تلقائيًا بين الأجهزة، ومسح بيانات المتصفح قد يحذفها. لا توجد حسابات مستخدمين أو مزامنة سحابية في هذه النسخة.

## المتطلبات
- Node.js 18 أو أحدث.
- Python 3.10 أو أحدث لواجهات Vercel Python.
- مفتاح API واحد على الأقل للمحادثة. يوصى بـ Gemini، وGroq كبديل.
- `MOONDREAM_API_KEY` لتحليل الصور.
- `HF_TOKEN` اختياري لتجربة الفيديو؛ قد لا يكون النموذج متاحًا أو مجانيًا، كما أن حد مهلة Vercel قد يمنع توليد فيديو طويل.

## التشغيل محليًا
1. انسخ `.env.example` إلى `.env` واملأ مفاتيحك. لا ترفع `.env` إلى GitHub.
2. ثبّت TypeScript: `npm install`
3. ابنِ الواجهة: `npm run build`
4. شغّل المشروع باستخدام بيئة تدعم Vercel Functions مثل Vercel CLI: `npx vercel dev`.

> فتح `public/index.html` مباشرة لا يشغّل واجهات Python API. يجب تشغيله عبر بيئة الخادم.

## النشر على Vercel
1. ارفع مجلد المشروع إلى مستودع GitHub خاص أو عام حسب رغبتك.
2. استورده في Vercel.
3. أضف مفاتيح API المطلوبة في Project Settings → Environment Variables.
4. أعد النشر. لا تضع أي مفتاح في ملفات `public` أو `src`.

## APIs
| الخدمة | الاستخدام | المتغير |
|---|---|---|
| Gemini | المحادثة الأساسية | `GEMINI_API_KEY` |
| Groq | السرعة وطلبات البرمجة | `GROQ_API_KEY` |
| Moondream | تحليل الصور | `MOONDREAM_API_KEY` |
| OpenRouter | محرك احتياطي | `OPENROUTER_API_KEY` |
| Cloudflare Workers AI | محرك احتياطي | `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN` |
| NVIDIA NIM | محرك احتياطي | `NVIDIA_API_KEY` |
| Mistral | محرك احتياطي | `MISTRAL_API_KEY` |
| Hugging Face | تجربة توليد الفيديو | `HF_TOKEN` |
| Pollinations | توليد الصور من الواجهة | لا يحتاج مفتاحًا في الإعداد الحالي؛ التوفر والسياسة قد يتغيران |

الحصص والأسعار وشروط الاستخدام تتغير حسب المزود والنموذج والحساب. لا تعتبر أي خدمة مجانية بلا حدود.

## ملاحظات وحدود معروفة
- Auto Pilot الحالي **موجّه قواعدي خفيف** وليس وكيلًا مستقلًا ينفذ مهام طويلة أو يكتب ملفات المشروع بنفسه.
- الصوت يعتمد على Speech Recognition/Speech Synthesis في المتصفح، وليس اتصالًا صوتيًا حيًا منخفض التأخير مثل Gemini Live. دعم اللهجة العربية يختلف حسب المتصفح والجهاز.
- توليد الفيديو تجريبي؛ واجهة Hugging Face المستخدمة قد تتغير، وقد تتجاوز مدة الاستجابة مهلة الاستضافة.
- توليد الصور يتم من المتصفح عبر Pollinations؛ لا تمر مفاتيح مزوداتك عبر الواجهة.
- لا توجد قاعدة بيانات أو تسجيل دخول أو مزامنة بين الأجهزة.
- هذه تحسينات أساسية وليست تدقيقًا أمنيًا شاملًا. قبل إطلاق عام، أضف rate limiting على مستوى الحافة/الاستضافة ومراقبة تكاليف ومفاتيح منفصلة لكل بيئة.
